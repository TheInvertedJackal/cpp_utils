# Mac's C++ Libraries
_I like having some libraries for some things that I tend to do over and over and over, or just some things that I like_

## The Content

This Library is split up into many folders, each with a differing small library.

Most method by method documentation is done in the .hpp files for any given lib.

Brief overviews and version numbers can be found below for each active library.

### STB Image - v1.0 - (On Hold)

A simple library for loading in an image and manipulating it's data pixel by pixel. Supports input and output from JPEGs and PNGs.

### CLIP v0.1(Active Development Pre - Release)

Command line prompts are the bread and butter of CLI programs. This library gives access to many default options.

### Benchmark Testing

An in-code solution for benchmarking a given piece of code and sending it 

### Logger v0.1 (In Pre Development)

A simple logger for logging error and other data to a file for later review. Helps with console output and traceability.

## Testing

There are tests for each of the given libraries that will be developed with time. All tests are held in the `testing` folder.
